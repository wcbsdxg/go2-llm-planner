# 正式 Demo 分镜脚本（目标总长 2:40，无声+字幕 或 照读解说均可）

## 录前检查（每次开录前 30 秒过一遍）

□ 浏览器开 localhost:11434 确认 "Ollama is running"
□ run.bat 已启动，终端(左)+3D窗口(右)并排，终端字号 16+
□ 已跑过一条"向前走"完成预热
□ demo_commands.txt 已打开（复制指令用）
□ 系统免打扰已开，OBS 混音器麦克风静音（无声版）
□ OBS 已点"开始录制"

---

【镜1 | 0:00-0:15 | 项目开场】
操作：窗口切到 README.md，滚动停在"架构"一节
口播/字幕：
"这是我的具身智能先行项目 go2-llm-planner。整条链路是：自然语言指令交给
本地部署的 Qwen3-8B 大模型做任务规划，输出 JSON 技能序列，经过安全校验后，
驱动宇树 Go2 在 MuJoCo 仿真里执行。下面看实际演示。"

【镜2 | 0:15-0:25 | 环境亮相】
操作：切到终端，光标停在"指令>"处，静止 1 秒
口播/字幕：
"规划模型完全跑在本地边缘侧，这是它就绪的状态。"

【镜3 | 0:25-0:50 | A1 基础移动】
操作：粘贴 demo_commands.txt 第 1 行"向前走"→回车
→ 等 JSON 打印完停 2 秒，鼠标移到 JSON 上
口播/字幕：
"第一条指令：向前走。终端里可以看到大模型输出的计划——一个 Move 技能，
速度 0.3 米每秒，持续 2 秒。这个计划通过了技能白名单和数值钳位校验，
Go2 正在执行。"

【镜4 | 0:50-1:10 | A2 转向控制】
操作：粘贴"左转90度"→回车，等执行完
口播/字幕：
"左转90度。模型把它换算成角速度 0.8 乘 2 秒，约 1.6 弧度，正好 90 度
多一点，执行出平滑的转向。"

【镜5 | 1:10-1:40 | A3 多段组合（压轴）】
操作：粘贴"向前走三步，右转，再向前走三步"→回车
→ 计划打印出 3 个 Move 时，鼠标逐行缓慢划过
口播/字幕：
"一个更复杂的复合指令：向前走三步，右转，再向前走三步。模型把它拆解成
三段——直走、右转90度、再直走，轨迹上走出一个标准的直角。这说明规划
不是逐句反应，而是对整条指令做了结构化分解。"

【镜6 | 1:40-2:00 | A4 多技能衔接】
操作：粘贴"走过去然后坐下"→回车
口播/字幕：
"再试跨技能的组合：走过去然后坐下。计划里同时出现移动和坐下两个技能，
顺序执行，最后坐姿收尾。"

【镜7 | 2:00-2:20 | A5 模糊指令】
操作：粘贴"随便动动"→回车
口播/字幕：
"最后故意给一条模糊指令：随便动动。模型没有被难住，它自主决策了一个
安全的前进动作——因为技能层有白名单和速度钳位，无论它怎么决策，
输出都在安全范围内。"

【镜8 | 2:20-2:40 | 过程留痕收尾】
操作：资源管理器打开 logs\sessions\，双击最新 jsonl 滚动几行；
再切到 logs\acceptance_*.md 的汇总表
口播/字幕：
"演示的每一步——大模型的原始输出、安全修正记录、每次执行结果——都写进
了会话日志，这是项目的全部过程记录。代码已开源，验收报告就在仓库里。
谢谢观看。"

【镜9 | 2:40 | 停止】
